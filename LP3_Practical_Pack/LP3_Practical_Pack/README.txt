LP3 PRACTICAL EXAM PACK
=======================

FOLDER STRUCTURE
----------------
DAA/Python  - 5 standalone Python programs
DAA/Java    - 5 standalone Java programs (each file has its own matching class name)
ML          - ML scripts and the four datasets uploaded in this chat
BT          - plain-text study notes, step-by-step instructions, and Solidity source code saved as .txt files

IMPORTANT
---------
1. Read this file and each folder's README.txt first.
2. Python scripts are intended to be run from a terminal. Use Python 3.10+ if possible.
3. Java programs need a JDK installed (javac/java available in terminal).
4. ML dependencies: open a terminal in the ML folder and run:
      python -m pip install pandas numpy scikit-learn matplotlib
5. ML scripts locate their CSV files relative to the script's own folder, so you can run them from any current directory.
6. Four datasets supplied by you are included: uber.csv, sales_data_sample (1).csv, diabetes (1).csv, Churn_Modelling.csv.
7. No email spam dataset was present in the uploaded files. ML/08_email_spam_knn_svm.py expects you to add a suitable email-spam CSV to the ML folder; follow that script's instructions.
8. BT Solidity code is saved as .txt as requested. Copy the contract source from the relevant .txt file into a new .sol file in https://remix.ethereum.org/ to compile it.
9. For BT practice, use Remix VM/local test environment first. Do not enter a real wallet recovery phrase or private key into any website or share it with anyone.
